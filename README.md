# Streamlit-Based AI Preparation Bot

An AI-powered placement preparation assistant built using Python, Streamlit, LangChain, Hugging Face, and FAISS.

## Features

- AI-based placement preparation assistant
- Answers questions using uploaded PDF documents
- PDF document loading and processing
- Text chunking using LangChain
- Semantic search using Hugging Face embeddings
- FAISS vector database for efficient document retrieval
- Hugging Face LLM integration
- Student-friendly and concise responses
- Supports multiple knowledge-base PDF files

## Technologies Used

- Python
- Streamlit
- LangChain
- Hugging Face
- Sentence Transformers
- FAISS
- PyPDF
- python-dotenv
